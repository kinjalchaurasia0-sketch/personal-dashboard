# personal-dashboard

A personal dashboard website built using HTML5 and CSS3 to create a customized homepage and a simple personal profile page.

## About the Project

This project is my first step toward building personalized web experiences. It combines a visually customized dashboard with an About Me page where I introduce myself, list my skills, and share my current learning goals.

The design features a scenic background image, a dark navigation bar, a Google-inspired search interface, and cards for personal reminders and useful resources.

## Features

### Personal Dashboard
- Custom navigation bar with links to Calendar, Gmail, and About Me.
- Google-inspired logo and search bar design.
- Card-based layout for a quote of the day, quick links, and current learning goal.
- Custom background wallpaper.
- Styled navigation links with hover effects.

### About Me Page
- Personal introduction and developer profile.
- Skills section featuring HTML5, CSS3, C++, and Python.
- Current learning goals.
- Quick links to YouTube, X (Twitter), and WhatsApp.
- Simple page layout with distinct sections and a footer.

## Technologies Used

- **HTML5** — Page structure, content, navigation, and forms.
- **CSS3** — Layout, colors, typography, background images, cards, and hover effects.

## How to Run

1. Download or clone this repository.
2. Keep `first.html`, `aboutme.html`, and `Wallpaper.jpg` in the correct locations.
3. Open `first.html` in a web browser to view the dashboard.
4. Select the About Me link to navigate to the profile page.

No additional software or dependencies are required to view the pages locally.
